# FrontFix

Focused homepage improvements for small and local businesses.

FrontFix helps businesses make the page customers see first clearer, easier to use on mobile, and easier to contact from — without selling a full-site rebuild by default.

## Launch scope
- Homepage structure and hierarchy
- Mobile usability cleanup
- Clearer contact / quote paths
- Copy and service hierarchy cleanup
- One revision
- Target delivery: 24–48 hours after approval and required access

## Prospect previews
Private-by-link concept previews live under `/preview/<slug>/`.

They are intentionally:
- not linked from the public FrontFix website;
- marked `noindex,nofollow`;
- excluded from crawler access in `robots.txt`;
- clearly labelled as FrontFix concepts rather than official client websites.

## Stack
Static HTML, CSS and vanilla JavaScript. No paid runtime dependencies.
